# References

Primary methodological reference:

- Christine Zhang, Dan Jurafsky, Chen Shani. **Learning Concepts, Not Tokens: Self-Supervised Semantic Alignment for Language Models.** arXiv:2603.29123, 2026.
- Earlier course-project version studied during project formulation: **Concept Training for Human-Aligned Language Models**.
- Official implementation used as a methodological reference: https://github.com/christine-zhang1/learning-concepts

This repository is an independent DA624 course-project implementation. It follows the published methodology at reduced scale and adds an optional context-preservation regularizer; it does not copy the official repository wholesale.
